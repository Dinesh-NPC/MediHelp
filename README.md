# MediHelp

MediHelp is a web-based application that predicts the risk of **cardiovascular, respiratory, and diabetes diseases** using machine learning models. It is designed to help users quickly assess their health risks and take preventive measures. The platform also features **user authentication** powered by **MongoDB**, ensuring a secure login experience.

---

## 📌 Features

- **Predictive Health Assessment**  
  - Cardiovascular Disease  
  - Respiratory Disease  
  - Diabetes  
- **Secure User Authentication** using MongoDB  
- **User-friendly Interface** built with HTML and CSS  
- **Machine Learning Powered**: Pre-trained Random Forest models provide reliable predictions  
- **Real-time Feedback**: Users receive immediate risk assessment after submitting health parameters  

---

## 🧰 Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Flask (Python)  
- **Database:** MongoDB (for user authentication)  
- **Machine Learning Model:** Random Forest (pre-trained)  
- **Python Libraries:** scikit-learn, pandas, numpy, Flask, pymongo  

---

## 🚀 How to Use

1. **Register/Login**  
   - Create an account or log in using your credentials.  
   - Authentication is securely managed using MongoDB.  

2. **Navigate to Prediction Pages**  
   - Choose between Cardiovascular, Respiratory, or Diabetes prediction.  

3. **Enter Health Data**  
   - Fill in required parameters such as age, weight, blood pressure, sugar levels, etc.  

4. **Get Predictions**  
   - Click **Predict** to see your risk assessment:  
     - ✅ **Low Risk**  
     - ⚠️ **Medium Risk**  
     - ❌ **High Risk**
